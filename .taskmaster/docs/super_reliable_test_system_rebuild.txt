# 超级可靠测试体系重建需求文档

## 项目背景

基于test-system-rebuild任务的现有成果，项目已建立了完整的测试执行环境，包括pytest框架、测试目录结构、环境配置等。当前需要在此基础上，实现"一键make test通过、前后端无报错、所有已有功能可验收"的最终目标。

## 项目架构

### 后端架构
- Django 4.2.7 + Python 3.13.6
- 数据模型：Expression、IdiomaticExpression、UserExpressionProgress等
- API接口：RESTful API，支持地道表达学习、AI助教、统计分析
- 数据库：MySQL，支持迁移和索引优化

### 前端架构
- Vue.js 3 + TypeScript + Vite
- 状态管理：Pinia
- 路由：Vue Router
- UI组件：ExpressionCard、LearningDashboard、AIAssistantChat等

### 测试架构
- 测试框架：pytest + pytest-django + pytest-cov
- 测试目录：unit、integration、e2e、factories、fixtures
- 测试配置：pytest.ini、test_settings、conftest.py

1. **make test 100%通过**：所有测试用例执行成功
2. **覆盖率≥80%**：代码测试覆盖率达到目标
3. **前后端无报错**：核心功能回归测试通过

5. **测试体系稳定**：测试执行稳定可靠

## 技术方案

### 测试工具链
- pytest：主要测试框架
- pytest-cov：覆盖率测试
- pytest-xdist：并行测试执行
- pytest-html：HTML测试报告
- radon：代码复杂度分析
- coverage：覆盖率报告

### 测试策略
- 单元测试：覆盖所有业务逻辑
- 集成测试：验证组件间协作
- 端到端测试：验证用户流程
- 回归测试：确保功能稳定

### 质量门禁
- 测试覆盖率阈值：80%
- 代码复杂度阈值：A级
- 测试执行时间：<10分钟
- 失败测试数量：0
