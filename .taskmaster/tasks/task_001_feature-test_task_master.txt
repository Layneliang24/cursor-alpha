# Subtasks:
## 1. 扩展Expression模型创建IdiomaticExpression [pending]
### Dependencies: None
### Description: 基于现有Expression模型扩展创建IdiomaticExpression模型，添加地道表达特有字段
### Details:
在backend/apps/english/models.py中扩展现有Expression模型，创建IdiomaticExpression子类。新增字段包括：expression_type（表达类型，如习语、俚语、固定搭配）、frequency_score（使用频率评分1-10）、formality_level（正式程度：informal/neutral/formal）、difficulty_level（难度等级1-5）、phonetic_transcription（音标）。使用Django的JSONField存储额外的元数据如变体形式、同义表达等。确保与现有Expression模型的兼容性，继承现有字段如content、translation、created_at等。

## 2. 创建ExpressionScenario和ExpressionSource模型 [pending]
### Dependencies: None
### Description: 设计并实现ExpressionScenario使用场景模型和ExpressionSource数据源管理模型
### Details:
创建ExpressionScenario模型存储地道表达的使用场景，字段包括：scenario_name（场景名称）、context_description（上下文描述）、example_dialogue（示例对话）、scenario_type（场景类型：business/casual/academic等）。创建ExpressionSource模型管理数据来源，字段包括：source_name、source_url、source_type（dictionary/forum/news等）、reliability_score（可靠性评分）、last_updated（最后更新时间）。建立与IdiomaticExpression的多对多关系，使用through参数定义中间表存储关联的额外信息。

## 3. 创建UserExpressionProgress用户学习进度模型 [pending]
### Dependencies: None
### Description: 设计用户表达学习进度跟踪模型，实现个性化学习数据管理
### Details:
创建UserExpressionProgress模型跟踪用户学习进度，字段包括：user（外键关联User模型）、expression（外键关联IdiomaticExpression）、mastery_level（掌握程度0-100）、review_count（复习次数）、correct_count（正确次数）、last_reviewed（最后复习时间）、next_review（下次复习时间）、learning_streak（连续学习天数）。使用JSONField存储详细的学习历史记录，包括每次学习的时间戳、答题结果、用时等。实现SM-2算法相关字段：easiness_factor（容易度因子）、interval（复习间隔）。

## 5. 创建数据库迁移文件和索引优化 [pending]
### Dependencies: None
### Description: 使用Django migration系统创建数据库变更文件，设计合理的数据库索引提升查询性能
### Details:
