# Description: 修复expressionStore.ts中的needReviewExpressions computed属性，确保其正确处理可能的空值。
# Details:
1. 在store中，确保expressions和userProgress有安全的初始值（如空数组）。
2. 重构needReviewExpressions computed属性，使用可选链和空值合并：
```javascript
const needReviewExpressions = computed(() => {
  const expressionList = expressions.value ?? [];
  const progressList = userProgress.value ?? [];
  
  return expressionList.filter(expr => {
    const progress = progressList.find(p => p.expression_id === expr.id);
    return progress && new Date(progress.next_review) <= new Date();
  });
});
```
