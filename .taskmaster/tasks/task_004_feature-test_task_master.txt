# Task ID: 4
# Title: 前端界面与组件开发
# Status: pending
# Dependencies: 3
# Priority: medium
# Description: 基于Vue.js 3开发现代化的地道表达学习界面
# Details:
在现有前端架构下新增idiomatic-expressions模块，采用Vue.js 3 + TypeScript + Vite技术栈。核心组件包括：1) ExpressionCard.vue表达卡片组件，支持卡片翻转动画 2) ScenarioPlayer.vue场景播放器，集成音频播放和字幕显示 3) LearningDashboard.vue学习仪表板，使用ECharts展示学习进度 4) AIAssistantChat.vue AI对话界面。使用Pinia状态管理，创建expressionStore、learningStore管理数据。采用Vue Router实现页面路由，集成现有认证守卫。UI设计遵循Material Design 3规范，使用Vuetify或PrimeVue组件库。实现响应式布局，支持桌面端、平板、手机多端适配。使用Vite构建工具，配置代码分割和懒加载优化性能。

# Test Strategy:
使用Vitest进行组件单元测试，覆盖组件渲染、用户交互、状态变更等场景。使用Vue Test Utils模拟用户操作，验证组件行为。集成Playwright进行E2E测试，测试完整的用户学习流程。使用Lighthouse进行性能测试，确保页面加载速度和用户体验。
